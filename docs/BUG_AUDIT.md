# Bug and risk audit

**Audit date:** 2026-11-04. Static source inspection and diff review only. No tests or services were run. “Confirmed” means the problematic code path was present in the pre-change source; fixes marked implemented are source-level only and still need Cyrus's manual verification.

Severity: **P0** immediate data/security exposure; **P1** high risk or core reliability defect; **P2** meaningful correctness/usability defect; **P3** low impact. Status is **Open** unless stated otherwise.

| ID | Severity / status | File and function | Evidence | Impact | Recommended fix | Regression risk |

| BUG-009 | P2 / Confirmed coverage gap, Open | `server.py` `make_backup()`, `restore_backup()` | Backup includes a fixed allowlist of JSON files and one skill file; excludes project sessions, brain settings, vault, usage and other state.
