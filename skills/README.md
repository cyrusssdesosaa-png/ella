# Skills

Cursor loads the one skill that matches the message. A longer Jarvis job loads the next skill when the step changes. The long detail stays in `profiles/`.

| Skill | Load when |
| --- | --- |
| `screenshot-analysis` | He sends a picture |
| `project-memory` | He says continue, or names his projects in general |
| `aura-unity` | Aura, capstone, `D:\capstone` |
| `god-local-ai` | GOD at `D:\GOD`, or Story Studio |
| `wally-client` | Wally Wombats, David, admin, rehab draft |
| `night-shift-reply` | A fan message or a chat screenshot |
| `desk-tools` | Translator or Read Aloud |
| `talk` | A check-in or a side-panel reply |
| `memory` | Saving or reading a fact |
| `day` | The morning check-in |
| `projects` | Listing nearby project folders |
| `token-scout` | Refreshing the free-model list |
| `adapt` | The weekly how-i-help rewrite |
| `use-the-skills` | A job that needs more than one skill, one step at a time |

Cursor copies live in `.cursor/skills/` and point at these folders. Edit here.
