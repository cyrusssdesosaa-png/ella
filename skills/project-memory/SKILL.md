# Project memory

Cyrus's builds are recorded in `profiles/`. The index is `profiles/INDEX.md`. How he talks and how he uses pictures is `profiles/operator.md`.

## Steps

1. Read `profiles/INDEX.md`.
2. Open the one profile whose name or path matches the task. Do not load the other profiles.
3. Follow that profile's path, stack, and "do not" list.
4. If he says "more", expand the current piece. Do not start a different project.
5. Large files go on `D:\`. Keep `C:` light.
6. Never copy `.env`, `credentials.local.txt`, or `appsettings.Production.json` into a reply or a profile.

## If the folder is missing

`profiles/earlier-apps.md` covers Hardwire, the birthday page, the loan tracker, and the assassin plan. Say the folder was not on disk at the last scan. Hardwire's successor is `D:\GOD`.

## Status line he can trust

When he asks where a project stands, answer with path, what is on disk, and the last known status from that profile. If you did not re-read the folder this turn, say the status is from the profile dated 2026-11-03.
