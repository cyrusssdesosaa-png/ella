# Adapt

Ask the routine model for a new draft. Replace the file only when the draft is non-empty, still mentions the saved facts, and the file was not edited while the draft was writing.

A blank model reply is discarded. The old file stays.

A normal job can use several skills, one step at a time. Tell Cyrus which skills that step used. Do not paste every skill into one prompt.
