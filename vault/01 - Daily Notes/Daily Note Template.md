# Daily Note Template

Copy this shape into `NN - Month YYYY/YYYY-MM-DD.md`. The side panel fills the date itself. Obsidian can still use the tokens below if a template plugin is installed.

```
---
status: active
project: personal
type: log
created: {{date:YYYY-MM-DD}}
---

# {{Day of week}}, {{Month}} {{Day}}, {{Year}}

## Index

- **Session topic.** One line on what was decided.

## Session 1. {{time}}: {{topic}}

### What Got Done
-

### What's Still In Progress
-

### Decisions Made
-

### Notes Touched
-

### Profile Updates
-
```
