## How he talks to the AI

Messages are short, casual, and often typed fast. Typos are normal. "more" means expand the thing already on screen, not start a new topic. "nice" means the direction is right, then keep going. "let me see the system" means show the layout, not another paragraph of options.

He wants the work done in the project folder. A plan is allowed when he asks to plan. After he agrees, build. Do not stall on a menu of choices he already answered.

Answers stay in plain English. Lead with the result. Skip a lecture about what the tool is.

## Pictures are the spec

He often sends a screenshot instead of describing the bug or the screen. The picture is the request.

Common shots:

- Unity Game view, Scene view, Console, or Inspector. Pink materials, missing arrows, wrong camera, compile errors.
- A phone screenshot of an app screen he wants rebuilt. Read the layout and the flow. Build an original screen. Do not copy another company's logo, name, or exact skin. The July 2026 loan chats were this: GCash-style shots, and the build had to be his own loan tracker.
- A chat screenshot from Fansly or a similar app. The text in the image is the fan message. Reply with the chatter skill.
- A Windows error, a Cursor error, or a website looking wrong. Read the visible error text before guessing.
- A recording frame or a website crop from the Wally Wombats job. Treat it as client evidence, then write it into the intake notes if he asks.

Read the image first. Say what it shows in a few sentences, including any exact error text. Then do the change the picture is asking for. If one corner is blurry or cut off, name that single gap and continue with the rest. Do not answer with a list of questions when the picture already shows the problem.

After a visual change, check the real screen when Unity or a browser is available. A code edit alone is not proof the picture's problem is gone.

## Machine habits

- Large projects live on `D:\`. Do not dump big Unity, model, or video files onto `C:`.
- Unity Editor in use for Aura is `6000.3.11f1` at `C:\Program Files\Unity\Hub\Editor\6000.3.11f1\Editor\Unity.exe`.
- Unity MCP is how the AI should inspect a scene when the Editor is open. If MCP is down, say so and read the files. Do not pretend the console was checked.
- Two Unity instances cannot open the same project. If the Editor already has it, use MCP or the open Editor.
- Cursor chats get slow when a session holds a huge screenshot history. Prefer a fresh chat for a new task, and do not re-attach old images.
- Secrets stay in local config (`.env`, `appsettings.Production.json`, `credentials.local.txt`). Never copy passwords, API keys, or mailbox passwords into a profile, a chat summary, or git.
